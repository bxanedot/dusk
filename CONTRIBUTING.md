# Contributing to Dusk

Contributions are welcome.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Keep changes focused and readable.
4. Test the behavior you changed.
5. Open a pull request describing what changed and why.

## Code expectations

- Do not include secrets, API keys, tokens, or private user data.
- Keep dependencies reasonable.
- Prefer clear code over unnecessary complexity.
- Match the existing style once the project structure is established.
- Large architectural changes should be explained clearly in the pull request.
