# Dusk brand assets

The official Dusk mark is the transparent crescent in this folder.

- dusk-logo-violet.svg — primary app/installer mark.
- dusk-logo-cyan.svg — cyan accent variant.
- dusk-logo-red.svg — red accent variant.
- src/assets/dusk-logo.svg — in-app primary vector asset.
- scripts/prepare-brand.ps1 — generates Windows PNG/ICO and NSIS installer artwork from the same crescent geometry.

Generated Windows assets are committed automatically by the Brand Assets workflow so the repository and release builds stay in sync.
